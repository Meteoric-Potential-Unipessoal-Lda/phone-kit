ТЕЛЕФОН-НАБОР 1.0 — оптимизация и проверка телефонов/планшетов Android по ADB
(Samsung, Xiaomi / Redmi / Poco, Realme / OPPO, Honor / Huawei, Motorola, Pixel и любые другие)

ИНТЕРФЕЙС И ЯЗЫК
  start.bat / start.command открывает страницу в браузере (адрес 127.0.0.1, работает без интернета):
  кнопки, галочки, ход работы. Окно консоли остаётся — отвечать можно и там, и там.
  Браузер не открылся — скопировать адрес из консоли в любой браузер. Только консоль: start.bat -Console
  Языки: русский, українська, English, Português, Español, Français, Italiano, Deutsch, Latviešu, Polski.
  Язык выбирается по системе, переключатель — справа вверху на странице; в консоли: start.bat -Lang en

ЧТО НОВОГО В 1.0
  - Диагностика показывает, что занимает память (фото, видео, загрузки, WhatsApp, Telegram, Viber)
    с советами, где почистить, и какие приложения сильнее всего тратят батарею.
  - План: профили Стандарт / Просто (для пожилых) / Ребёнок (семейный DNS) / Бережно / Максимум.
  - «Было / стало» (память, процессы, место) и отчёт для клиента: страница client_report.html
    в папке отчёта, на странице набора — кнопка «Отчёт для клиента» (сохраняется в PDF).
  - Откат выборочно: отметить на странице, что вернуть (в консоли — номера через пробел).
  - При запуске набор проверяет новую версию на GitHub (без интернета — молча дальше; -NoUpdateCheck — не проверять).

ОДИН РАЗ У СЕБЯ
  prepare.bat — кладёт в tools\ ADB для Windows и Mac и PowerShell для Mac
  (если рядом лежит папка tv-kit — берёт всё оттуда, ничего не качая).
  Без prepare.bat тоже работает: на Windows при первом запуске набор сам скачает ADB (нужен интернет).
  Mac без Windows: один раз в Терминале  brew install powershell android-platform-tools  (https://brew.sh)
  Свежая версия: https://github.com/Meteoric-Potential-Unipessoal-Lda/phone-kit/releases/latest

У КЛИЕНТА
  1. Спросить клиента: чем пользуется (Bixby, Samsung Pay, Smart View, Mi Cloud, «Найти устройство»,
     Галерея/Музыка производителя...), нужна ли блокировка рекламы через DNS, детский ли телефон.
  2. Клиент включает на телефоне режим разработчика и «Отладку по USB»
     (подсказка по маркам — пункт H на экране подключения).
     Samsung One UI 6+: временно выключить «Автоблокировщик».
  3. AnyDesk -> скопировать папку phone-kit на рабочий стол клиента ->
     Windows: start.bat;  Mac: Терминал -> bash ~/Desktop/phone-kit/start.command
  4. Подключение телефона:
     - кабелем: в уведомлении USB выбрать «Передача файлов», на экране разрешить отладку
       («Всегда разрешать с этого компьютера»);
     - по Wi-Fi (Android 11+, без драйверов, лучший вариант если Windows не видит Samsung):
       «Беспроводная отладка» -> «Подключить устройство по коду» -> в наборе пункт W -> ввести 6 цифр.
       Windows может спросить разрешение брандмауэра для adb — разрешить (частная сеть).
  5. Пункт 2 «Оптимизация»: набор сам делает диагностику и показывает план с галочками.
     [x] — уже выбрано: обычно достаточно просто Enter -> «да».
     Номер пункта ПЕРЕКЛЮЧАЕТ галочку (у отмеченного снимает!) — вводить номера только
     того, что хочешь изменить. Перед «да» набор покажет список того, что будет сделано.
     [ ] — не выбрано, но доступно: например, «Частный DNS AdGuard» (реклама в браузере и приложениях)
     включается вводом его номера.
     Пункт 1 «Диагностика» сам ничего не отключает.
  6. Проверка телефона руками -> перезагрузка с проверкой (рекомендуется) -> забрать архив и backups\.
     По Wi-Fi: после перезагрузки телефон обычно сам выключает «Беспроводную отладку» — включи её снова;
     если не подключится сам — «Подключить устройство по коду», набор найдёт окно и спросит код.
  7. В конце: выключить на телефоне «Отладку по USB»/«Беспроводную отладку»; Samsung — включить
     обратно «Автоблокировщик». Закрыть окно набора, удалить папку phone-kit у клиента.

МЕНЮ
  1) Диагностика — только чтение, ничего не меняет. Отчёт + архив в reports\.
  2) Оптимизация — диагностика -> план -> «да» -> изменения партиями по 5 с проверкой
     (рабочий стол, Настройки, клавиатура, SystemUI); проблема -> откат партии и стоп.
  3) Откат — по журналу backups\<имя>.json (или state.json из архива отчёта).

ЧТО В ПЛАНЕ
  - Анимации 0.5x (отмечено).
  - Частный DNS AdGuard — режет рекламу в приложениях и браузере (не отмечено, по желанию клиента;
    на детском телефоне предлагается «Семейный» с фильтром взрослых сайтов). Если с ним пропадает
    интернет — набор сам возвращает как было.
  - Очистка кэша приложений — отмечено, только если память заполнена больше 85%. Необратимо, но
    безопасно: данные, переписки и вход в приложения не трогает.
  - Подозрительные приложения (не отмечено): чистильщики/ускорители, установленные из APK со
    спецвозможностями, админы устройства, без значка — показать владельцу; отключение обратимо,
    удалять потом обычным способом.
  - Лишнее системное: реклама, аналитика, сбор данных, партнёрский мусор. По умолчанию отмечено
    только «Recommended» из базы, без значка в меню и не функции. Приложения со значком,
    Bixby, «Найти устройство», облака, браузеры и т.п. — «спросить владельца», не отмечены.
    Сначала pm disable-user (видно в Настройки -> Приложения как «Отключено»); если прошивка не
    даёт (бывает на Xiaomi) — pm uninstall -k --user 0 (только для основного пользователя, откат
    возвращает пакет командой install-existing).
  - Фон: сторонние приложения, которые больше месяца не открывали, но они висят в памяти —
    запрет работы в фоне (отмечено; мессенджеры, банки, будильники, трекеры детей не трогаются).

НИКОГДА НЕ ТРОГАЕТ
  Связь и SIM, звонилку, SMS, клавиатуры, рабочий стол, Настройки, SystemUI, Google Play и сервисы
  Google, аккаунты Samsung/Xiaomi, Knox, Samsung kgclient (блокирует телефон!), «Безопасность» и
  менеджер разрешений Xiaomi, обновления прошивки, камеру, галерею, биометрию, платежи и кошельки,
  родительский контроль (Family Link, Samsung Kids), будильник, приложения по умолчанию,
  службы спецвозможностей, администраторов, всё, чем пользовались за последний месяц,
  и пакеты, отключённые до нас. Ничего не удаляет насовсем, root/прошивки — нет.

ПРИСЛАТЬ CLAUDE АРХИВ (перетащить к себе в C:\cleanmytv\reports)
  - красные/жёлтые сообщения, прошивка вернула пакеты, телефон не вернулся после перезагрузки;
  - подозрительные приложения в разделе 6 отчёта;
  - жалобы клиента, которые набор не объяснил (тормоза при хорошей памяти, нагрев, батарея);
  - редкая марка (Tecno/Infinix/ZTE/Huawei без Google) — сначала пункт 1.

ЕСЛИ ТЕЛЕФОН НЕ ЗАГРУЖАЕТСЯ ПОСЛЕ ОПТИМИЗАЦИИ
  Набор сам предложит откат, если телефон виден по кабелю. Иначе: подождать 10 минут,
  принудительная перезагрузка (питание + громкость вниз 10-15 с), потом пункт 3.
  Сброс к заводским НЕ делать.

ФАЙЛЫ
  phonekit.ps1  — сам набор (PowerShell 5.1 в Windows, PowerShell 7 на Mac)
  data\uad.tsv  — база пакетов Universal Android Debloater Next Generation (GPL-3.0),
                  5300+ пакетов с уровнями Recommended / Advanced / Expert / Unsafe
  data\ru.tsv   — наши русские пояснения и правила (ok / ask / protect) — сильнее базы
  reports\      — отчёты;  backups\ — журналы для отката;  tools\ — ADB и PowerShell для Mac
