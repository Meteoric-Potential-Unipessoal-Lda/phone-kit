# phone-kit Mobile (бета)

Чистка **этого же телефона без компьютера**. Приложение подключается к самому себе через «Беспроводную отладку»
Android 11+ (как компьютер с `adb`) и выполняет логику `phonekit.ps1`: те же правила защиты (генерируются в `Pat.java`
из `phonekit.ps1`), та же база (`data/uad.tsv`, `ru.tsv`, `ads.tsv`), те же тексты (`data/lang`), партии по 5 с проверкой
рабочего стола / Настроек / клавиатуры / SystemUI и откат по журналу.

- Сопряжение: код из окна «Подключить устройство с помощью кода» вводится в уведомление (`PairReceiver`, RemoteInput)
  или в само приложение при разделённом экране. Порт ищется по mDNS (`_adb-tls-pairing._tcp`), подключение — всегда к `127.0.0.1`.
- Подключение: `_adb-tls-connect._tcp` → TLS 1.3 (Conscrypt) с сертификатом ключа приложения.
- Само приложение (`net.zherdyev.phonekit`) никогда не отключается и не ограничивается.
- Журнал хранится в папке приложения — перед удалением приложения нужно сделать откат.
- На Android 10 и старше приложение только объясняет, что нужен phone-kit на компьютере.

Сборка: `bash mobile/build.sh` (нужен Android SDK: build-tools + platform). Тесты без телефона: `bash tests/mobile/run.sh`.
Строки приложения — `mobile/strings.tsv` (ключи `x…`), остальные тексты берутся из `data/lang/*.json`.
